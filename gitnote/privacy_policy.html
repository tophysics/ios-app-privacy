GitNote — 基于 GitHub 的 Markdown 笔记应用

生效日期：2026年10月28日

1. 概述

GitNote 是一款基于 GitHub 的本地优先 Markdown 笔记应用。你的笔记与数据只属于你自己。本应用不收集、不上传、不出售任何用户个人信息，我们没有自己的服务器，也不设任何后台数据库。你的笔记以 Markdown 文件形式保存在你自己的 GitHub 仓库中，账户信息通过 iCloud 在你的设备之间同步。

核心原则：零数据收集、零分析追踪、零广告、零第三方 SDK。所有数据仅在「你的设备 ↔ GitHub ↔ Apple iCloud」之间直接流动，绝不经过开发者的任何服务器。

2. 数据的存储与流向

本地优先 你的数据由你掌控，分布在以下三处，均不受开发者控制：

笔记内容
Markdown 文件 · 存储在你自己的 GitHub 仓库与设备本地
GitHub 账户信息
登录凭证 / 访问令牌 · 通过 iCloud 在你的多台设备间同步
应用设置与偏好
本地存储 · 保存在你的设备上

3. 不收集的数据

无 开发者从不收集、也无法访问以下任何数据：

  • 个人身份信息（姓名、邮箱、电话、年龄、性别）
  • 设备标识符（IDFA、IDFV、广告标识符）
  • 位置数据（GPS、IP 定位）
  • 通讯录、照片、相机、麦克风
  • 分析数据、崩溃日志、行为遥测
  • 你的笔记内容与 GitHub 凭证

4. iCloud 同步

仅用于同步账户信息。GitNote 使用 Apple 提供的 iCloud（CloudKit / iCloud 钥匙串）在你的多台设备之间同步 GitHub 账户登录信息，以便你无需重复登录。该同步完全由 Apple 的基础设施处理并端到端保护，开发者无法访问、读取或控制其中的任何内容。

你可以随时在 iOS「设置 — Apple ID — iCloud」中关闭 iCloud 同步，或在应用内退出登录以清除已同步的账户信息。

5. GitHub 说明

GitNote 通过 GitHub 官方 API 读写你自己的笔记仓库。所有请求均由你的设备直接发往 GitHub，不经过任何中间服务器。你与 GitHub 之间的数据交互受 GitHub 自身隐私政策约束，建议你查阅 GitHub 的隐私条款以了解其数据处理方式。开发者不会获取、存储或分析你的 GitHub 账户、仓库或笔记内容。

6. 网络与第三方

  • 无自有服务器 — 开发者不运营任何后台或数据库
  • 无分析 SDK — 无 Firebase、Mixpanel、友盟等
  • 无广告 SDK — 不含任何广告框架或广告追踪器
  • 无崩溃上报 — 不向任何监控服务发送数据
  • 无社交登录 — 不含 Facebook、Google 等第三方认证
  • 有限的第三方服务 — 仅使用 GitHub（笔记存储）与 Apple iCloud（账户同步），二者均直接由你的设备访问

7. 权限

最小权限。GitNote 仅请求实现核心功能所必需的能力，如网络访问（用于连接 GitHub）与 iCloud（用于同步账户信息）。应用不会请求位置、相机、麦克风、通讯录、照片等与笔记功能无关的权限。

8. 数据保留与删除

你的数据完全由你掌控，可通过以下方式彻底删除：

  • 在应用内退出登录 — 清除本地及 iCloud 中同步的 GitHub 账户信息
  • 删除 GitHub 仓库中的笔记文件 — 从源头移除你的笔记内容
  • 删除应用 — 移除设备上的所有本地数据

由于开发者不持有任何你的数据副本，删除操作无需联系我们即可完成。

9. 数据安全

你的笔记与账户信息的安全性由 GitHub、Apple iCloud 以及你的设备系统共同保障。数据传输过程使用行业标准加密（如 HTTPS / TLS）。由于开发者不存储任何数据，我们不成为你数据的持有方或风险点。

10. 儿童隐私

Privacy Policy

GitNote — A GitHub-based Markdown notes app

Effective Date: October 28, 2026

GitNote is a local-first, GitHub-based Markdown notes app. Your notes and data belong to you alone. This app does not collect, upload, or sell any personal information. We operate no servers of our own and maintain no backend database. Your notes are saved as Markdown files in your own GitHub repository, and your account information is synced across your devices via iCloud.

Core principle: Zero data collection, zero analytics tracking, zero ads, zero third-party SDKs. All data flows directly between "your device ↔ GitHub ↔ Apple iCloud" and never passes through any developer server.

2. Data Storage & Flow

Local-first Your data is under your control, distributed across the following three places, none of which the developer controls:

Note content
Markdown files · Stored in your own GitHub repository and locally on your device
GitHub account info
Login credentials / access tokens · Synced across your devices via iCloud
App settings & preferences
Local storage · Saved on your device

3. Data We Do Not Collect

None The developer never collects, and cannot access, any of the following data:

  • Personal identity information (name, email, phone, age, gender)
  • Device identifiers (IDFA, IDFV, advertising ID)
  • Location data (GPS, IP-based location)
  • Contacts, photos, camera, microphone
  • Analytics data, crash logs, behavioral telemetry
  • Your note content or GitHub credentials

4. iCloud Sync

For account sync only. GitNote uses Apple's iCloud (CloudKit / iCloud Keychain) to sync your GitHub login information across your devices, so you don't have to sign in repeatedly. This sync is handled entirely by Apple's infrastructure with end-to-end protection; the developer cannot access, read, or control any of its contents.

You can turn off iCloud sync at any time in iOS "Settings — Apple ID — iCloud", or sign out within the app to clear the synced account information.

5. About GitHub

GitNote reads and writes your own notes repository through GitHub's official API. All requests are sent directly from your device to GitHub, without passing through any intermediate server. Data exchanges between you and GitHub are governed by GitHub's own Privacy Policy; we recommend reviewing GitHub's privacy terms to understand how it processes data. The developer does not obtain, store, or analyze your GitHub account, repositories, or note content.

6. Network & Third Parties

  • No self-hosted servers — The developer operates no backend or database
  • No analytics SDK — No Firebase, Mixpanel, etc.
  • No ad SDK — Contains no advertising frameworks or ad trackers
  • No crash reporting — No data sent to any monitoring service
  • No social login — No Facebook, Google, or other third-party authentication
  • Limited third-party services — Only GitHub (note storage) and Apple iCloud (account sync), both accessed directly by your device

7. Permissions

Minimal permissions. GitNote only requests capabilities essential to its core functions, such as network access (to connect to GitHub) and iCloud (to sync account information). The app does not request permissions unrelated to note-taking, such as location, camera, microphone, contacts, or photos.

8. Data Retention & Deletion

Your data is entirely under your control and can be completely deleted in the following ways:

  • Sign out within the app — Clears GitHub account info synced locally and in iCloud
  • Delete note files in your GitHub repository — Removes your note content at the source
  • Delete the app — Removes all local data on your device

Since the developer holds no copies of your data, deletion requires no contact with us.

9. Data Security

The security of your notes and account information is jointly safeguarded by GitHub, Apple iCloud, and your device's operating system. Data transmission uses industry-standard encryption (such as HTTPS / TLS). Since the developer stores no data, we are neither a holder of nor a risk point for your data.

10. Children's Privacy

This app is not designed for children under 13, and we do not knowingly collect personal information from any user (including children). Using this app requires your own GitHub account and is subject to the corresponding terms of service.

11. Changes to This Policy

If our data processing practices change, we will update this policy and note the new effective date. Given the app's "zero data collection" architecture, future changes will remain minimal and transparent.

  • 위치 데이터(GPS, IP 기반 위치)
  • 연락처, 사진, 카메라, 마이크
  • 분석 데이터, 충돌 로그, 행동 원격 분석
  • 귀하의 노트 내용 및 GitHub 자격 증명

4. iCloud 동기화

계정 정보 동기화에 한해 사용. GitNote는 Apple이 제공하는 iCloud(CloudKit / iCloud 키체인)를 사용하여 귀하의 여러 기기 간에 GitHub 계정 로그인 정보를 동기화하므로 반복 로그인할 필요가 없습니다. 이 동기화는 전적으로 Apple의 인프라에 의해 처리되고 종단 간 보호되며, 개발자는 그 어떤 내용에도 접근, 읽기 또는 제어할 수 없습니다.

귀하는 언제든지 iOS 「설정 — Apple ID — iCloud」에서 iCloud 동기화를 끄거나, 앱 내에서 로그아웃하여 동기화된 계정 정보를 삭제할 수 있습니다.

5. GitHub 안내

GitNote는 GitHub 공식 API를 통해 귀하의 노트 저장소를 읽고 씁니다. 모든 요청은 귀하의 기기에서 GitHub로 직접 전송되며 어떠한 중간 서버도 거치지 않습니다. 귀하와 GitHub 간의 데이터 상호작용은 GitHub 자체의 개인정보 처리방침의 적용을 받으므로, GitHub의 데이터 처리 방식을 이해하려면 GitHub의 개인정보 조항을 확인하시기 바랍니다. 개발자는 귀하의 GitHub 계정, 저장소 또는 노트 내용을 취득, 저장 또는 분석하지 않습니다.

6. 네트워크 및 제3자

  • 자체 서버 없음 — 개발자는 어떠한 백엔드나 데이터베이스도 운영하지 않음
  • 분석 SDK 없음 — Firebase, Mixpanel 등 없음
  • 광고 SDK 없음 — 광고 프레임워크나 광고 추적기를 포함하지 않음
  • 충돌 보고 없음 — 어떠한 모니터링 서비스에도 데이터를 전송하지 않음
  • 소셜 로그인 없음 — Facebook, Google 등 제3자 인증을 포함하지 않음
  • 제한된 제3자 서비스 — GitHub(노트 저장)와 Apple iCloud(계정 동기화)만 사용하며, 둘 다 귀하의 기기에서 직접 접근

7. 권한

최소 권한. GitNote는 네트워크 접근(GitHub 연결용)과 iCloud(계정 정보 동기화용) 등 핵심 기능 구현에 필수적인 능력만 요청합니다. 위치, 카메라, 마이크, 연락처, 사진 등 노트 기능과 무관한 권한은 요청하지 않습니다.

8. 데이터 보유 및 삭제

귀하의 데이터는 전적으로 귀하가 통제하며, 다음 방법으로 완전히 삭제할 수 있습니다:

  • 앱 내에서 로그아웃 — 로컬 및 iCloud에 동기화된 GitHub 계정 정보 삭제
  • GitHub 저장소의 노트 파일 삭제 — 원본에서 귀하의 노트 내용 제거
  • 앱 삭제 — 기기의 모든 로컬 데이터 제거

개발자는 귀하의 데이터 사본을 전혀 보유하지 않으므로, 삭제 시 당사에 연락할 필요가 없습니다.

9. 데이터 보안

귀하의 노트와 계정 정보의 보안은 GitHub, Apple iCloud 및 귀하의 기기 시스템이 공동으로 보장합니다. 데이터 전송에는 업계 표준 암호화(HTTPS / TLS 등)를 사용합니다. 개발자는 어떠한 데이터도 저장하지 않으므로, 귀하의 데이터의 보유자나 위험 지점이 되지 않습니다.
