隐私政策

GitNote — 基于 GitHub 的 Markdown 笔记应用

生效日期：2026年10月28日

1. 概述

GitNote 是一款基于 GitHub 的本地优先 Markdown 笔记应用。你的笔记与数据只属于你自己。本应用不收集、不上传、不出售任何用户个人信息，我们没有自己的服务器，也不设任何后台数据库。你的笔记以 Markdown 文件形式保存在你自己的 GitHub 仓库中，账户信息通过 iCloud 在你的设备之间同步。

核心原则：零数据收集、零分析追踪、零广告、零第三方 SDK。所有数据仅在「你的设备 ↔ GitHub ↔ Apple iCloud」之间直接流动，绝不经过开发者的任何服务器。

2. 数据的存储与流向

本地优先 你的数据由你掌控，分布在以下三处，均不受开发者控制：

笔记内容
Markdown 文件 · 存储在你自己的 GitHub 仓库与设备本地
GitHub 账户信息
登录凭证 / 访问令牌 · 通过 iCloud 在你的多台设备间同步
应用设置与偏好
本地存储 · 保存在你的设备上

3. 不收集的数据

无 开发者从不收集、也无法访问以下任何数据：

  • 个人身份信息（姓名、邮箱、电话、年龄、性别）
  • 设备标识符（IDFA、IDFV、广告标识符）
  • 位置数据（GPS、IP 定位）
  • 通讯录、照片、相机、麦克风
  • 分析数据、崩溃日志、行为遥测
  • 你的笔记内容与 GitHub 凭证

4. iCloud 同步

仅用于同步账户信息。GitNote 使用 Apple 提供的 iCloud（CloudKit / iCloud 钥匙串）在你的多台设备之间同步 GitHub 账户登录信息，以便你无需重复登录。该同步完全由 Apple 的基础设施处理并端到端保护，开发者无法访问、读取或控制其中的任何内容。

你可以随时在 iOS「设置 — Apple ID — iCloud」中关闭 iCloud 同步，或在应用内退出登录以清除已同步的账户信息。

5. GitHub 说明

GitNote 通过 GitHub 官方 API 读写你自己的笔记仓库。所有请求均由你的设备直接发往 GitHub，不经过任何中间服务器。你与 GitHub 之间的数据交互受 GitHub 自身隐私政策约束，建议你查阅 GitHub 的隐私条款以了解其数据处理方式。开发者不会获取、存储或分析你的 GitHub 账户、仓库或笔记内容。

6. 网络与第三方

  • 无自有服务器 — 开发者不运营任何后台或数据库
  • 无分析 SDK — 无 Firebase、Mixpanel、友盟等
  • 无广告 SDK — 不含任何广告框架或广告追踪器
  • 无崩溃上报 — 不向任何监控服务发送数据
  • 无社交登录 — 不含 Facebook、Google 等第三方认证
  • 有限的第三方服务 — 仅使用 GitHub（笔记存储）与 Apple iCloud（账户同步），二者均直接由你的设备访问

7. 权限

最小权限。GitNote 仅请求实现核心功能所必需的能力，如网络访问（用于连接 GitHub）与 iCloud（用于同步账户信息）。应用不会请求位置、相机、麦克风、通讯录、照片等与笔记功能无关的权限。

8. 数据保留与删除

你的数据完全由你掌控，可通过以下方式彻底删除：

  • 在应用内退出登录 — 清除本地及 iCloud 中同步的 GitHub 账户信息
  • 删除 GitHub 仓库中的笔记文件 — 从源头移除你的笔记内容
  • 删除应用 — 移除设备上的所有本地数据

由于开发者不持有任何你的数据副本，删除操作无需联系我们即可完成。

9. 数据安全

你的笔记与账户信息的安全性由 GitHub、Apple iCloud 以及你的设备系统共同保障。数据传输过程使用行业标准加密（如 HTTPS / TLS）。由于开发者不存储任何数据，我们不成为你数据的持有方或风险点。

10. 儿童隐私

本应用不针对 13 岁以下儿童设计，我们不会故意收集任何用户（包括儿童）的个人信息。使用本应用需要你自己的 GitHub 账户，并受相应服务条款约束。

11. 隐私政策变更

如数据处理方式发生变更，我们将更新此政策并标注新的生效日期。鉴于本应用「零数据收集」的架构，未来的变更将保持最小化且透明。
